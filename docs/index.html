Gwarancja Bezpieczeństwa

Za D2 UberApp nie dostaniesz bana.

Wielu graczy obawia się programów wspomagających ze względu na rygorystyczny system anty-cheat (Warden). D2 UberApp został od podstaw zaprojektowany w architekturze Screen-Only, całkowicie izolowanej od procesu gry.

01

Działa wyłącznie na screenach

Aplikacja pobiera klatkę obrazu pulpitu przez standardowe Windows API (identycznie jak programy typu OBS Studio, Discord czy Narzędzie Wycinanie). Nigdy nie ingeruje w kod gry.

02

Brak czytania pamięci gry

D2 UberApp nie dotyka pamięci RAM procesu D2R.exe. Nie skanuje struktur pamięci ani wskaźników, eliminując jakiekolwiek ryzyko detekcji sygnaturowej.

03

Brak wstrzykiwania kodu (No DLL Injection)

Do gry nie są wstrzykiwane żadne biblioteki DLL, haki pamięciowe ani modyfikowane pliki gry. Wszystkie obliczenia OCR i bazy danych odbywają się w zewnętrznym procesie Pythona.

01 / Filary Aplikacji

Sanktuarium pod pełną kontrolą.

Koniec z ręcznym spisywaniem dropów, szukaniem widełek na zewnętrznych stronach i przelogowywaniem na dziesiątki mułów. D2 UberApp łączy natywne API Windows z najnowocześniejszym modelem wizyjnym Google.

01

Globalny skrót klawiszowy Win32 przechwytuje tooltip przedmiotu pod kursorem bezpośrednio podczas gry. Natychmiastowy dźwięk SFX potwierdza pomyślne dodanie do bazy.

02

Darmowy Gemini AI (Wymagany)

Szybki model gemini-2.5-flash-lite z Google AI Studio. Wymagany jest darmowy klucz API (bez karty kredytowej), który bez problemu wystarcza na tysiące skanów.

03

Katalog Widełek (Rolls)

Wbudowana kanoniczna baza danych automatycznie porównuje zmienne statystyki z wartościami min-max i wylicza procentową wartość od LOW do PERFECT (100%).

04

03 / Precyzja Katalogowa

Koniec z szacowaniem na oko.

W Diablo II: Resurrected różnica między najniższym a najwyższym rollem w unikatach i runewords decyduje o tysiącach jednostek wartości. D2 UberApp kalkuluje każdy parametr co do procenta.

Jak to działa w D2 UberApp?

  • ✓ Autodetekcja ramki tooltipa: Algorytm wycina idealny prostokąt opisu przedmiotu bez tła gry.
  • ✓ Wielojęzyczne OCR Gemini: Bez problemu odczytuje polskie znaki (ę, ą, ś) oraz angielską terminologię D2R.
  • ✓ Kanoniczne dopasowanie: Baza catalog.sqlite przechowuje oficjalne zakresy min-max dla każdego afiksu.
  • ✓ Ocena procentowa (Roll Rating): Automatyczne plakietki PERFECT (100%), HIGH, MID, LOW.
  • ✓ Skrót handlowy: Gotowy zapis do trade (np. Hoto 40 Res, Arach 120ED, CTA 6/6/4).

06 / Szybki Start

Uruchomienie w 4 prostych krokach.

Aplikacja nie wymaga zewnętrznych serwerów – cała baza działa lokalnie w plikach SQLite na Twoim dysku. Wystarczy darmowy klucz API z Google AI Studio.

01

Pobierz Repozytorium

Sklonuj kod źródłowy z GitHuba lub pobierz archiwum ZIP na dysk.

git clone https://github.com/twoj-profil/d2-uberapp.git
02

Zainstaluj Pakiety

Zainstaluj wymagane zależności w środowisku Python (rekomendowany Python 3.10+).

pip install -r requirements.txt
03

Darmowy Klucz Gemini (Wymagany)

Pobierz darmowy klucz z Google AI Studio, skopiuj .env.example na .env i wklej klucz.

GEMINI_API_KEY="AIzaSy..."
04

Uruchom Aplikację

Kliknij dwukrotnie start.bat. Skrypt zwolni porty i uruchomi Companion HUD oraz Web App.

start.bat (lub python app.py)
07 / Częste Pytania

Wszystko, co chcesz wiedzieć.

Masz wątpliwości dotyczące bezpieczeństwa, kosztów lub kompatybilności? Przeczytaj odpowiedzi poniżej.

Czy korzystanie z D2 UberApp grozi banem?

Nie, nie dostaje się za nią bana. Aplikacja działa wyłącznie na zrzutach ekranu (screenach). Nie czyta pamięci RAM procesu gry, nie wstrzykuje żadnych bibliotek DLL i nie modyfikuje plików D2R. Dla gry jest w 100% niewidoczna, dokładnie tak samo jak OBS Studio czy Discord.

Czy muszę płacić za Google Gemini API?

Nie, nie musisz płacić. Google AI Studio udostępnia całkowicie darmowy pakiet (Free Tier) bez konieczności podawania karty kredytowej. Darmowy limit na model gemini-2.5-flash-lite w zupełności wystarcza do codziennej gry i skanowania tysięcy przedmiotów. Pamiętaj jednak, że klucz API jest wymagany do działania funkcji skanera.

Czy aplikacja wspiera polską wersję językową gry?

Tak! Model Gemini bezbłędnie rozpoznaje zarówno polskie nazwy (np. Korbacz, Pajęcza Szarfa, Runa Jah), jak i angielskie odpowiedniki. Cały interfejs posiada przełącznik języka w nagłówku.

Gdzie zapisywane są moje przedmioty?

Wszystkie dane przechowywane są lokalnie na Twoim komputerze w pliku bazy danych SQLite (data/stash.sqlite). Masz pełną kontrolę i prywatność swoich danych.
