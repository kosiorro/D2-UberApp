# Skill tree layout

`skills_complete.json` is a local snapshot of the same layout source referenced by
the user's `d2help/skills.html`:

https://raw.githubusercontent.com/feored/halbu-editor/main/static/data/generated/skills/v105/skills_complete.json

Retrieved 2026-09-15. The application uses `id`, `row`, `column` and `reqskills`
to reproduce the reference tree layout without a network dependency.
The existing Sword Mastery record maps to Blade Mastery in this source.
Original icons, descriptions and persistent skill identifiers remain in `skills.json`.
