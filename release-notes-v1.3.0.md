## D2 UberApp v1.3.0 — integracja ze sklepem

- Integracja z D2 UberApp Market: https://market.d2app.xyz.
- Tworzenie list online jednym kliknięciem i udostępnianie ich przez link.
- Synchronizacja wybranych list i przedmiotów ze sklepem.
- Tworzenie, aktualizacja i usuwanie anonimowych list zabezpieczonych hasłem.
- Publikowanie buildów postaci w serwisie online.
- Ulepszony panel umiejętności postaci.
- README z opisem integracji i zrzutem ekranu list sklepu.
- Landing page wyłączony z repozytorium i paczek aplikacji.

### Pobieranie

- **D2UberApp_Setup_v1.3.0.exe** — instalator Windows.
- **D2UberApp_Windows_x64.zip** — wersja przenośna.

Instalator zachowuje istniejące ustawienia użytkownika. Moduł sklepu pozostaje w fazie beta.
