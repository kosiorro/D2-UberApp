## D2 UberApp v1.3.3 — aktualizacje na dole aplikacji

- Sekcja „Aktualizacje aplikacji / App updates” znajduje się teraz na dole panelu oraz widoku WWW.
- Instrukcja podłączenia Gemini API pozostaje na górze, gdy klucz nie został skonfigurowany.
- Zachowano sprawdzanie przy starcie, pobieranie oraz instalację z ponownym uruchomieniem.

### Pobieranie

- **D2UberApp_Setup_v1.3.3.exe** — instalator Windows.
- **D2UberApp_Windows_x64.zip** — wersja portable.

Użytkownicy v1.3.2 mogą pobrać i zainstalować aktualizację z aplikacji.
